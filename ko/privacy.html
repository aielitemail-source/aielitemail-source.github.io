개인정보처리방침

최종 업데이트: 2026년 8월 8일

1. 수집하는 정보

AI Elite는 애플리케이션 운영에 필요한 최소한의 정보만 수집합니다:

계정 정보: TikTok OAuth를 통해 등록할 때 귀하의 TikTok 사용자명과 고유 사용자 ID를 받습니다. 비밀번호는 저장하지 않습니다.

사용 데이터: 서비스 개선을 위해 애플리케이션의 익명 사용 지표(처리된 동영상 등)를 기록합니다.

콘텐츠: 당사 애플리케이션을 통해 처리하는 동영상은 로컬에서 처리되며 당사 서버에 영구적으로 저장되지 않습니다.

2. 정보 사용 방식

수집한 정보는 오직 다음 목적으로만 사용합니다:

- 콘텐츠 번역 및 적응 서비스 제공 및 유지

- TikTok 계정 접근 인증 및 승인

- 기능 및 사용자 경험 개선

- 필요한 경우 법적 의무 준수

3. 정보 공유

귀하의 개인정보를 제3자에게 판매하거나 공유하지 않습니다. 단, 다음 경우는 예외입니다:

- 귀하의 명시적 동의가 있는 경우

- 법적으로 요구되는 경우

- 애플리케이션 운영을 돕는 서비스 제공업체(예: TikTok API 및 번역 서비스)와 공유하며, 이들은 기밀유지 계약의 적용을 받습니다

4. 데이터 보안

귀하의 정보를 보호하기 위해 합리적인 보안 조치를 시행합니다. 그러나 인터넷을 통한 전송 방법은 100% 안전하지 않습니다.

5. 데이터 보관

계정이 활성 상태인 동안 계정 정보를 보관합니다. 익명 사용 데이터는 통계 분석을 위해 최대 24개월까지 보관될 수 있습니다.

6. 귀하의 권리

귀하는 다음 권리가 있습니다:

- 개인정보 접근

- 데이터 삭제 요청

- 언제든지 동의 철회

- 관할 데이터 보호 기관에 불만 제기

7. 쿠키

당사 애플리케이션은 자체 쿠키를 사용하지 않습니다. TikTok 인증 서비스는 자체 정책에 따라 자체 쿠키를 사용할 수 있습니다.

8. 본 정책의 변경

본 정책을 업데이트할 권리를 보유합니다. 중요한 변경 사항은 애플리케이션을 통해 공지됩니다.
